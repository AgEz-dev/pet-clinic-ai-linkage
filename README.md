# 宠安康 × VetClaw · 全栈业务闭环 & AI 分诊联动展示站

宠物门诊业务系统（Spring Boot 2.7 + Vue 3 + MySQL 8）与分诊 Agent（FastAPI + RAG）的联合展示站。

- `index.html` —— 项目全景：业务系统核心闭环（挂号防超卖、处方安全审核闸门、药品台账条件原子扣库与动态分页、疫苗三级预警、五维雷达）+ AI 联动拓扑、工程约束与实测数据（238 + 378 = 616 测试全绿）
- `demo.html` —— 五场景可交互演示：① 分诊问答 ② 预问诊 ③ 病历起草 ④ 处方闸门与库存扣减 ⑤ 疫苗预警批量催办与进销存分页

单文件静态站点，无外部依赖，离线可直接打开。

## 本地预览

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```
